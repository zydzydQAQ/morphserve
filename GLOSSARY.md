# MorphServe Domain Glossary

Canonical domain and architectural vocabulary for `morphserve`. All modules, interfaces, tests, and design documents use these exact terms.

## Paradigm & Model Concepts

- **CPTG (Cross-Paradigm Transition Graph)**: Unified execution graph representation across autoregressive understanding/reasoning (`AR` / `VLM`) and diffusion generation (`DiT` / `MMDiT`) turns within one session.
  - **`tight_mot` (`BAGEL-7B-MoT`)**: Mixture-of-Transformers architecture where understanding and generation share token sequence state; cross-paradigm state is a multi-turn `NaiveCache` KV context (`main`, `cfg_text`, `cfg_img`).
  - **`bridge_mllm_dit` (`InternVL-U`)**: Bridge-coupled MLLM + MMDiT architecture where cross-paradigm state is a compact conditioning tensor bundle (`diffusion_inputs`, ~24–32 MiB) rather than full VLM KV history.
- **`CPTGModelAdapter`**: Deep Python data-plane model module in `python/morphserve/models/` hiding model loading, runtime compatibility shims, turn preparation, `AR` token decoding, `DiT` denoising, `CPTGRequestSpec` construction, and flat `uint8` state pack/unpack behind one uniform interface (`BagelCPTGAdapter`, `InternVLUCPTGAdapter`, `SyntheticCPTGAdapter`).
- **`SessionContext`**: Opaque per-session worker state managed by a `CPTGModelAdapter` (`NaiveCache` + CoW prefix + GPU loopback tensor for `tight_mot`; conditioning bridge tensors + target grid dimensions for `bridge_mllm_dit`).

## Memory & Paging (`TriPool-VMM`)

- **`TriPoolVMM`**: Instance-owned dual-tier virtual memory manager (`include/morphserve/vmm/` + `src/morphserve/vmm/`) sharing one physical pool across three virtual address arenas: `2 MiB` Contiguous-VA Persistent KV regions, `64 MiB` super-handle Scoped Transient Scratchpads (`MemPool` + `CUDAPluggableAllocator` for FLUX/Qwen VAE spikes), and `64 MiB` Opportunistic Secondary Expert slices with drop-clean eviction, thinking-session KV watermark LRU swap, and single authoritative `kv_free_bytes` accounting.
- **`PageBackend` (`CudaPageAdapter` / `HostMmapPageAdapter`)**: C++ page-mapping seam beneath `TriPoolVMM` (`include/morphserve/vmm/page_backend.hpp`), pairing runtime `dlopen("libcuda.so.1")` `cuMemMap` execution on A100 GPUs with POSIX `mmap` execution in CPU `CTest`/`pytest` suites (replacing duplicate Python VMM simulation).
- **`VmmNaiveCache`**: Sealed drop-in `NaiveCache` replacement (`python/morphserve/vmm/kv_cache.py`) owning in-place Arena-1 `append_inplace(layer_idx, k_new, v_new)` growth (`2,048` tokens per `2 MiB` page for `BAGEL`) without `torch.cat` reallocations and preserving base-pointer identity across `LECP CoW` forks and host swap cycles.
- **`NumaMemfdMirror`**: RAII C++ process-shareable, NUMA-bound (`mbind` / `numa_tonode_memory`), CUDA-pinned host weight mirror (`include/morphserve/runtime/numa_mirror.hpp`) backed by `memfd_create` and `/proc/<leader_pid>/fd/<fd>` `MAP_SHARED` attachment (1 shared mirror per NUMA socket, bypassing `/dev/shm` caps).
- **`ExpertPartitionSpec`**: Declarative specification of which decoder blocks, parameter names, forward entrypoints, and optional `VAE` module belong to a pageable secondary expert (`BAGEL` 28-block generation expert; `InternVL-U` 20-block `GenerationDecoder`).
- **`LayerExpertPager`**: Unified `TriPool-VMM` expert pager (`python/morphserve/vmm/pager.py`) binding `Parameter.data` permanently to fixed Expert VA views, streaming missing blocks asynchronously during Step-1 compute (`expert_alpha`), and applying asymmetric transient `VAE` scoping.
- **`NaiveHostOffloader` & `StaticFissionDropper`**: Baseline secondary-weight lifecycle helpers driven by `ExpertPartitionSpec` inside `CPTGModelAdapter`, eliminating duplicated parameter-walking loops across `BagelCPTGAdapter` and `InternVLUCPTGAdapter`.
- **`WorkerBudgetPlanner`**: C++ physical memory budget module (`include/morphserve/control/budget_planner.hpp`) sizing `super_pool_mib`, `fine_kv_pool_mib`, and PyTorch memory caps across unconstrained (`40/80 GB`) and quota-capped (`12 GiB`) regimes.
- **`expert_alpha`**: Fraction (`[0.0, 1.0]`) of secondary generation expert blocks currently mapped in GPU HBM on a worker.

## Execution Interception, Kernels & Preemption

- **`BagelExecutionInterceptor`**: Single permanent, `mode`-aware Python data-plane execution coordinator (`python/morphserve/worker/bagel_interceptor.py`) owning generation-only (`mode == "gen"`) `LayerExpertPager` wait gating, Step-0 `HalfNodeH2DPacer` slot release, `[B, D]` packed GEMM batched `AR` steps delegating KV growth strictly to `VmmNaiveCache.append_inplace`, and `BagelSharedPrefixPatch` activation.
- **`PreemptEdfController`**: `torch`-free, GIL-free C++17 real-time EDF preemption controller (`include/morphserve/control/preempt_edf.hpp`) tracking EMA block/AR latencies, computing adaptive `layer_chunk` bounds `k >= 1`, and selecting slack-coalesced `AR` microbatches identically across live workers and `ClusterSimulator`.
- **`LECP CoW` (`SharedPrefixCache`)**: Longest Exact Causal Prefix Copy-on-Write KV sharing across `CFG` branches (`cow_fork_context`, `rebind_cow_prefix`), eliminating ~50% multi-turn KV HBM duplication with O(1) storage-pointer identity detection.
- **`FlashPrefix-CFG`**: Two-pass `FA2` shared-prefix attention + fused Triton online-softmax `LSE` merge, gated by `should_use_flash_prefix_split` (`L_shared >= max(256, 1.5 * Q_len)` for `Q_len <= 2048`; `L_shared >= 4 * Q_len` for `Q_len > 2048`), falling back losslessly to single-copy direct-workspace non-causal attention below threshold.
- **`GpuInPlaceLoopback`**: Zero-CPU `VAE -> uint8 -> Catmull-Rom PIL-exact bicubic resize -> ViT/VAE` loopback on GPU, eliminating PNG/PIL round-trips across interleaved turns.
- **`UnifiedPreemptiveScheduler`**: Python worker preemption adapter binding `PreemptEdfController` decisions to `BagelExecutionInterceptor` `AR` microbatch execution with zero DiT recomputation.

## Topology, Control Engine, Runtime Transport & Exactness

- **`MorphControlEngine`**: Deterministic C++17 cluster control engine (`include/morphserve/control/morph_controller.hpp`) unifying `PolicyTraits`, calibrated `ClusterPhysicsProfile`, `DualPathMorphRouter`, `HalfNodeH2DPacer` reservations, event-driven multi-turn `CPTG` session state transitions (`StepDirective`), Turn-0 OOM retry, post-DiT return shipping, and steady-state `k×` Joint SLO aggregation across live `MorphServeClusterEngine` and `ClusterSimulator`.
- **`ClusterTopologyProfile` & `ClusterPhysicsProfile`**: Unified three-tier interconnect bandwidth/contention model (`intra_half` PCIe switch, `inter_socket` cross-NUMA, `inter_node` RDMA) and Phase-0/1 calibrated operator-latency / unloaded-SLO profile (`T_unloaded`, `k×` class SLOs) in `include/morphserve/control/topology.hpp`.
- **`DualPathMorphRouter`**: Stateful C++ placement and routing module (`include/morphserve/control/router.hpp`) owning `WorkerState` ledgers, initial GPU admission, static-fission rank pairing, `HalfNodeH2DPacer` slot reservations, and analytical routing between **Path A (`state_ship`)** and **Path B (`in_place_morph`)**.
- **`ClusterSimulator`**: Native C++17 discrete-event simulator (`include/morphserve/control/simulator.hpp` + `cmd/morphserve_sim.cpp`) stepping `MorphControlEngine` and byte-accurate GPU HBM ledgers across `8 -> 16 -> 64` GPUs.
- **`PeerByteTransport` (`NcclPeerAdapter` / `TcpPeerAdapter` / `InMemoryPeerAdapter`)**: Unified C++17 point-to-point byte transport seam (`include/morphserve/runtime/peer_transport.hpp`) isolating `dlopen("libnccl.so.2")` dedicated-stream GPU P2P, POSIX `TCP_NODELAY` sockets, and in-memory test channels behind RAII handles.
- **`WorkerRuntime` & `WorkerFleet`**: Thin Python tensor-lifecycle dispatcher (`WorkerRuntime`) holding live `torch.Tensor`/`Event` references and driving `CPTGModelAdapter` + `PeerByteTransport`, exposed to `MorphServeClusterEngine` through `MpSpawnGpuWorkerFleet`, `MultiNodeWorkerFleet`, and `InProcessWorkerFleet`.
- **`ExactnessEvaluator` (`Exactness Red Line`)**: Canonical verification module (`python/morphserve/bench/exactness.py`) enforcing **Bit-Exact `SHA256`** for `TriPool-VMM`, Dual-Path Morphing, and Preemptive Scheduling, and **Zero-Approximation Mathematical Equivalence** (`100%` greedy `AR` token match, `8x8` windowed `SSIM`, `PSNR`, `MAE_u8`) for `FlashPrefix-CFG` and `GpuInPlaceLoopback`.
