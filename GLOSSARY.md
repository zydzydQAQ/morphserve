# MorphServe Domain Glossary

Canonical domain and architectural vocabulary for `morphserve`. All modules, interfaces, tests, and design documents use these exact terms.

## Paradigm & Model Concepts

- **CPTG (Cross-Paradigm Transition Graph)**: Unified execution graph representation across autoregressive understanding/reasoning (`AR` / `VLM`) and diffusion generation (`DiT` / `MMDiT`) turns within one session.
  - **`tight_mot` (`BAGEL-7B-MoT`)**: Mixture-of-Transformers architecture where understanding and generation share token sequence state; cross-paradigm state is a multi-turn `NaiveCache` KV context (`main`, `cfg_text`, `cfg_img`).
  - **`bridge_mllm_dit` (`InternVL-U`)**: Bridge-coupled MLLM + MMDiT architecture where cross-paradigm state is a compact conditioning tensor bundle (`diffusion_inputs`, ~24–32 MiB) rather than full VLM KV history.
- **`CPTGModelAdapter`**: Deep Python data-plane model module in `python/morphserve/models/` hiding model loading, runtime compatibility shims, turn preparation, `AR` token decoding, `DiT` denoising, `CPTGRequestSpec` construction, and flat `uint8` state pack/unpack behind one uniform interface (`BagelCPTGAdapter`, `InternVLUCPTGAdapter`, `SyntheticCPTGAdapter`).
- **`SessionContext` & `BagelSessionContext`**: Opaque per-session worker state managed by a `CPTGModelAdapter`. `BagelSessionContext` encapsulates the `tight_mot` multi-turn state (`NaiveCache` / `VmmNaiveCache`, `LECP CoW` prefix binding, and GPU loopback `uint8` image buffer); `InternVLUCPTGAdapter` holds compact conditioning bridge tensors and target grid dimensions for `bridge_mllm_dit`.

## Memory & Paging (`TriPool-VMM`)

- **`TriPoolVMM`**: Instance-owned dual-tier virtual memory manager (`include/morphserve/vmm/` + `src/morphserve/vmm/`) sharing one physical pool across three virtual address arenas: `2 MiB` Contiguous-VA Persistent KV regions, `64 MiB` super-handle Scoped Transient Scratchpads (`MemPool` + `CUDAPluggableAllocator` for FLUX/Qwen VAE spikes), and `64 MiB` Opportunistic Secondary Expert slices with drop-clean eviction, thinking-session KV watermark LRU swap, and single authoritative `kv_free_bytes` accounting. Supports `simulated=True` POSIX `mmap` execution without CUDA hardware.
- **`VmmOutOfMemoryError`**: Typed memory-exhaustion exception raised by `TriPoolVMM` and `VmmNaiveCache` when physical pool handles and thinking-KV swap reclamation cannot satisfy an allocation without overflow, enabling deterministic OOM handling and bounded Turn-0 retry.
- **`PageBackend` (`CudaPageAdapter` / `HostMmapPageAdapter`)**: C++ page-mapping seam beneath `TriPoolVMM` (`include/morphserve/vmm/page_backend.hpp`), pairing runtime `dlopen("libcuda.so.1")` `cuMemMap` execution on A100 GPUs with POSIX `mmap` execution in CPU `CTest`/`pytest` suites.
- **`VmmNaiveCache`**: Sealed drop-in `NaiveCache` replacement (`python/morphserve/vmm/kv_cache.py`) owning in-place Arena-1 growth via its polymorphic `append_kv(layer_idx, k_new, v_new, ...)` entry point (`2,048` tokens per `2 MiB` page for `BAGEL`) without `torch.cat` reallocations and preserving base-pointer identity across `LECP CoW` forks and host swap cycles.
- **`NumaMemfdMirror`**: RAII C++ process-shareable, NUMA-bound (`mbind` / `numa_tonode_memory`), CUDA-pinned host weight mirror (`include/morphserve/runtime/numa_mirror.hpp`) backed by `memfd_create` and `/proc/<leader_pid>/fd/<fd>` `MAP_SHARED` attachment (1 shared mirror per NUMA socket, bypassing `/dev/shm` caps).
- **`ExpertPartitionSpec`**: Declarative specification of which decoder blocks, parameter names, forward entrypoints, and optional `VAE` module belong to a pageable secondary expert (`BAGEL` 28-block generation expert; `InternVL-U` 20-block `GenerationDecoder`).
- **`LayerExpertPager`**: Unified `TriPool-VMM` expert pager (`python/morphserve/vmm/pager.py`) binding `Parameter.data` permanently to fixed Expert VA views, streaming missing blocks asynchronously during Step-1 compute (`expert_alpha`), and applying asymmetric transient `VAE` scoping.
- **`NaiveHostOffloader` & `StaticFissionDropper`**: Baseline secondary-weight lifecycle helpers driven by `ExpertPartitionSpec` inside `CPTGModelAdapter`, eliminating duplicated parameter-walking loops across `BagelCPTGAdapter` and `InternVLUCPTGAdapter`.
- **`WorkerBudgetPlanner`**: C++ physical memory budget module (`include/morphserve/control/budget_planner.hpp`, exposed via `morphserve.engine.config`) sizing `super_pool_mib`, `fine_kv_pool_mib`, and PyTorch memory caps across unconstrained (`40/80 GB`) and quota-capped (`12 GiB`) regimes (`compute_internvlu_memory_plan`, `compute_internvlu_quota_overrides`, `verify_internvlu_memory_quota`).
- **`expert_alpha`**: Fraction (`[0.0, 1.0]`) of secondary generation expert blocks currently mapped in GPU HBM on a worker.

## Execution Interception, Kernels & Preemption

- **`BagelExecutionInterceptor`**: Single permanent, `mode`-aware Python data-plane execution coordinator (`python/morphserve/worker/bagel_interceptor.py`) absorbing the legacy `BagelSharedPrefixPatch` hooks behind `ContextVar`-scoped `shared_prefix_cfg_scope(...)` with instance-scoped attention workspaces, owning generation-only (`mode == "gen"`) `LayerExpertPager` wait gating, Step-0 `HalfNodeH2DPacer` slot release, and `[B, D]` packed GEMM batched `AR` steps delegating KV growth strictly to `VmmNaiveCache.append_kv`.
- **`PreemptEdfController`**: `torch`-free, GIL-free C++17 real-time EDF preemption controller (`include/morphserve/control/preempt_edf.hpp`) tracking EMA block/AR latencies, computing adaptive `layer_chunk` bounds `k >= 1`, and selecting slack-coalesced `AR` microbatches identically across live workers and `ClusterSimulator` (constructed through `MorphControlEngine::make_edf_controller`).
- **`UnifiedPreemptiveScheduler` & `PreemptionSession`**: Python worker preemption adapter (`python/morphserve/worker/preemptive_scheduler.py`) binding `PreemptEdfController` decisions to `BagelExecutionInterceptor` `AR` microbatch execution with zero DiT recomputation. `PreemptionSession` is the RAII execution scope returned by `run_session()` managing hook activation, pager generation-mode gating, and clean teardown.
- **`LECP CoW` (`SharedPrefixCache`)**: Longest Exact Causal Prefix Copy-on-Write KV sharing across `CFG` branches (`cow_fork_context`, `rebind_cow_prefix`), eliminating ~50% multi-turn KV HBM duplication with O(1) storage-pointer identity detection.
- **`FlashPrefix-CFG`**: Two-pass `FA2` shared-prefix attention + fused Triton online-softmax `LSE` merge, gated by `should_use_flash_prefix_split` (`L_shared >= max(256, 1.5 * Q_len)` for `Q_len <= 2048`; `L_shared >= 4 * Q_len` for `Q_len > 2048`), falling back losslessly to single-copy direct-workspace non-causal attention below threshold.
- **`GpuInPlaceLoopback`**: Zero-CPU `VAE -> uint8 -> Catmull-Rom PIL-exact bicubic resize -> ViT/VAE` loopback on GPU, eliminating PNG/PIL round-trips across interleaved turns.

## Topology, Control Engine & Runtime Transport

- **`MorphControlEngine`**: Deterministic C++17 cluster control engine (`include/morphserve/control/morph_controller.hpp`) shared directly by live `MorphServeClusterEngine` and `ClusterSimulator`. Unifies `PolicyConfig` / `PolicyTraits`, calibrated `ClusterPhysicsProfile`, `DualPathMorphRouter`, `HalfNodeH2DPacer` reservations, `PreemptEdfController`, event-driven multi-turn `CPTG` session state transitions, Turn-0 OOM retry, post-DiT return shipping, and canonical steady-state `k×` Joint SLO report aggregation (`joint_slo_goodput_rps == steady_joint_slo_goodput_rps`, `joint_slo_attainment_pct == steady_joint_slo_attainment_pct`, alongside `full_trace_goodput_rps`, `vmm_physical_pool_mib`, and `kv_host_swap_ins`).
- **`ClusterTopologyProfile` & `ClusterPhysicsProfile`**: Unified three-tier interconnect bandwidth/contention model (`intra_half` PCIe switch, `inter_socket` cross-NUMA, `inter_node` RDMA) and Phase-0/1 calibrated operator-latency / unloaded-SLO profile (`T_unloaded`, decoupled `k_AR` / `k_DiT` class SLOs) in `include/morphserve/control/topology.hpp`.
- **`DualPathMorphRouter`**: Stateful C++ placement and routing module (`include/morphserve/control/router.hpp`) owning `WorkerState` ledgers, initial GPU admission, static-fission rank pairing, `HalfNodeH2DPacer` slot reservations, and analytical routing between **Path A (`state_ship`)** and **Path B (`in_place_morph`)**.
- **`ClusterSimulator`**: Native C++17 discrete-event simulator (`include/morphserve/control/simulator.hpp` + `cmd/morphserve_sim.cpp`) stepping `MorphControlEngine`, `PreemptEdfController`, and byte-accurate GPU HBM ledgers across `8 -> 16 -> 64` GPUs, accepting explicit `custom_sessions` inputs cleanly through `simulate_cluster_point(...)`.
- **`PeerByteTransport` (`NcclPeerAdapter` / `TcpPeerAdapter` / `InMemoryPeerAdapter`)**: Unified C++17 point-to-point byte transport seam (`include/morphserve/runtime/peer_transport.hpp`) and unified Python module (`python/morphserve/runtime/peer_transport.py`, exposing `NcclPeerAdapter` / `DirectNcclMesh`, `TcpPeerEndpoint`, `TcpByteMesh`, `InMemoryPeerMesh`, `InMemoryByteBus`, `find_free_tcp_port`), isolating `dlopen("libnccl.so.2")` dedicated-stream GPU P2P, POSIX `TCP_NODELAY` sockets, and in-memory test channels behind RAII handles.
- **`WorkerRuntime`, `LocalNodeWorkerHost` & `WorkerFleet`**: Thin Python tensor-lifecycle dispatcher (`WorkerRuntime`) holding live `torch.Tensor`/`Event` references and driving `CPTGModelAdapter` + `PeerByteTransport`. `LocalNodeWorkerHost` owns local worker-process supervision and IPC for a single node, exposed to `MorphServeClusterEngine` through `MpSpawnGpuWorkerFleet`, `TcpMultinodeWorkerFleet`, and `InProcessWorkerFleet`.

## Benchmarking, Harness & Exactness

- **`RunWindowOptions`**: Immutable per-suite execution window and think-time configuration dataclass (`morphserve.engine.config`) passed directly to `MorphServeClusterEngine.run_suite(..., run_options=...)` so sweeps never mutate `engine.policy` in place.
- **`BenchmarkRunner`**: Shared lifecycle harness (`python/morphserve/bench/harness.py`) owning `MorphServeClusterEngine` startup, repeated `run_suite(..., run_options=...)` sweeps, canonical `compact_report_dict` compaction, phase/quadrant breakdowns, zero-OOM `interpolate_slo_threshold_qps` curves, and guaranteed `shutdown()` + `gc.collect()` teardown, with `engine_factory` / `fleet_factory` injection seams for offline testing.
- **`ExactnessEvaluator` (`Exactness Red Line`)**: Canonical verification module (`python/morphserve/bench/exactness.py`) enforcing **Bit-Exact `SHA256`** for `TriPool-VMM`, Dual-Path Morphing, and Preemptive Scheduling, and **Zero-Approximation Mathematical Equivalence** (`100%` greedy `AR` token match, `8x8` windowed `SSIM`, `PSNR`, `MAE_u8`, plus downstream `MMVet`, `OWLv2` GenEval, and `CLIP` editing alignment) for `FlashPrefix-CFG` and `GpuInPlaceLoopback`. Suite construction (`build_m3_active_accuracy_suite`, `build_online_phase_shift_suite`) lives separately in `python/morphserve/bench/interleaved_bench.py`.
